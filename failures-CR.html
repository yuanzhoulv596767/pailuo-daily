save 把我改好的剧本又写回旧稿

我以为是：POST /api/save 只写 project.json；剧本.md 是只读源，改完不会再被碰。

错在第几步：第一步——我先把盘上的 剧本.md 改好，再 GET /api/load，再 POST /api/save。server.py:300-308 在 save 里把 body.get("script") 回写成 剧本.md；而 doc["script"] 是 project.json 里存的旧值，于是新稿被自己的保存动作覆盖。更险的是：回滚实测时 剧本.md 的 hash 是 49898617…，我拿它跟「drill 前」比觉得一致就算通过，没去追它为什么不是改后的 7e38f345…——差点把「已经被覆盖」当成「回滚成功」。

下次先查什么：动剧本与 project.json 两侧时，只走一次 save，把新稿放进 body.script；改完两侧各 grep 一次关键句，不只看 hash 相等。

状态：已修（11-16 22:01 重新 save，两侧一致并 grep 复核）。

返回值里带 undefined，程序整个输出失败

我以为是：return { status: e.status, code: e.error?.code } 拿不到值时给个空就行，不影响已经做完的写文件。

错在第几步：最后一步——程序跑完、文件确实写进去了，但返回值里有 undefined 字段，harness 报 code run failed (invalid-output): program completion must be lossless JSON。失败发生在写入之后，我拿不到任何回执，只能靠下一轮读盘猜。

下次先查什么：返回值只放一定存在的字段（String(x ?? "") / Boolean(x)）；有副作用的程序，先打印结果再做收尾返回。

状态：已修（后续程序统一转字符串/布尔返回）。
